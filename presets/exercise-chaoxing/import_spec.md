# 超星学习通题库导入格式说明

本 preset 对应超星学习通「课程题库」Excel 导入格式。

## 官方模板参考

原始模板文件：`presets/importQuestionTemplateNew.xlsx`（由平台提供，本项目仅作格式参考，不直接填充）。

## 表头结构（19 列）

| 列 | 字段 | 必填 | 说明 |
|---|---|---|---|
| A | 目录 | 否 | 路径式 `/计算机`、`/子文件夹/子文件夹`，空 = 根目录 |
| B | 题目类型 | 是 | 16 种题型（本 preset 支持 6 种） |
| C | 大题题干 | 是 | 大题题干 |
| D | 小题题型 | 否 | 仅「大题套小题」题型用（阅读理解） |
| E | 小题题干 | 否 | 同上 |
| F | 正确答案 | 视题型 | 单选 `C`，多选 `BCD`，判断 `A`/`B`，简答 `A` |
| G | 答案解析 | 否 | |
| H | 难易度 | 否 | 易/中/难，默认中 |
| I | 知识点 | 否 | |
| J | 标签 | 否 | 多个用 `；` 分隔 |
| K | 选项数 | 视题型 | 数字，填空题 = 空数 |
| L-S | 选项A~H | 视题型 | 填空题这里是各空答案；简答题答案是 A 列内容 |

## 支持的 6 种题型

| 内部 type | 超星题型名 | 独立/嵌套 | F列答案 | K列选项数 | L-S列 |
|---|---|---|---|---|---|
| `single_choice` | 单选题 | 独立 | `B` | `len(options)` | 选项逐列填 |
| `multiple_choice` | 多选题 | 独立 | `BCD` | `len(options)` | 选项逐列填 |
| `fill_blank` | 填空题 | 独立 | 空 | `len(answer)` | answer 逐空填到 L、M、N... |
| `true_false` | 判断题 | 独立 | `A`/`B` | `2` | L=`正确`, M=`错误` |
| `short_answer` | 简答题 | 独立 | `A` | `1` | L=答案全文 |
| `reading_comprehension` | 阅读理解 | 嵌套 | 空（大题行） | 空 | 空（大题行） |

## 嵌套题型行结构（阅读理解）

阅读理解采用「大题行 + 小题行」结构：

```
R01: /目录 | 阅读理解 | [大段材料] |  |  |  |  | 中 | 知识点 | 标签    ← 大题行
R02:  |  |  | 单选题 | [小题题干] | B | 解析 |  | 4 | 选项A | 选项B | ...   ← 小题行（D~S）
R03:  |  |  | 判断题 | [小题题干] | A |  |  | 2 | 正确 | 错误              ← 小题行
```

- **大题行**：填 A(目录)、B(题型)、C(材料)、H(难易度)、I(知识点)、J(标签)
- **小题行**：填 D(小题题型)、E(小题题干)、F(答案)、G(解析)、K(选项数)、L-S(选项)
- 小题行的 A/B/C/H/I/J 留空，继承大题

## 不支持的题型（后续按需扩展）

连线题、排序题、测评题、完型填空、共用选项题、选做题、分录题、资料题、名词解释、论述题。

## 导入注意事项

1. **数据从第 3 行开始**：超星平台导入时会跳过前 2 行（第 1 行表头 + 第 2 行提示行）。本项目生成的 xlsx 已自动在第 2 行留空，题目从第 3 行开始，可直接导入。
2. 选项数必须与实际选项个数一致，否则导入失败
3. 标签多个用中文分号 `；` 分隔
4. 难易度留空时系统默认为「中」
